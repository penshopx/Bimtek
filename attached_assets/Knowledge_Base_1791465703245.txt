File pengganti Knowledge Base

Buka proyek **BIMTEK** di Replit, unggah file tersebut ke Agent, lalu tempel:

```
Terapkan file TSX lampiran sebagai pengganti:
src/app/knowledge-base/page.tsx

1. Buat checkpoint terlebih dahulu.
2. Bandingkan dengan file existing; pertahankan penyesuaian proyek
   yang diperlukan tanpa menghilangkan koreksi konten.
3. Jangan mengubah database, dependency, atau halaman lain.
4. Jalankan lint, typecheck, dan build yang tersedia.
5. Periksa filter kategori, accordion, status referensi,
   tautan sumber, dan tampilan ponsel.
6. Laporkan perubahan dan hasil pemeriksaan yang sebenarnya.

Jangan deploy produksi. Jika ada konflik atau pemeriksaan gagal,
laporkan penyebabnya—jangan mengklaim selesai.
```

**Setelah Replit selesai, kirim ringkasan hasil dan error jika ada.** Kita tutup satu pekerjaan ini terlebih dahulu, lalu lanjut memperbaiki **nilai jenjang Klinik hingga payload AI**, bukan hanya label tombol.
