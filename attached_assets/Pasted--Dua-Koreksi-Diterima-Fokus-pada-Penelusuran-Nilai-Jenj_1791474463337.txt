## 📋 Checklist Validasi per Lapisan

### **Layer 1 — UI**
- [ ] Pilihan "Ahli Muda" mengirim value `7` (bukan `"Ahli Muda"` atau `"7"`)
- [ ] Pilihan "Ahli Madya" mengirim value `8`
- [ ] Pilihan "Ahli Utama" mengirim value `9`
- [ ] Pilihan Teknisi/Operator mengirim angka spesifik (misal: jenjang 3, 4, 5, 6), bukan rentang seperti `"3-6"`
- [ ] Label tampilan tetap ramah pengguna, tapi `value` attribute adalah integer

### **Layer 2 — Request API**
- [ ] Payload HTTP body memiliki field jenjang bertipe integer
- [ ] Tidak ada field jenjang duplikat (misal: `jenjang` dan `jenjang_teks` bersamaan)
- [ ] Tidak ada konversi string→integer di client yang bisa gagal

### **Layer 3 — Validasi Server**
- [ ] Server menolak request dengan jenjang bertipe string (400 Bad Request)
- [ ] Server menolak jenjang di luar range yang valid untuk jabatan tertentu
- [ ] Server memvalidasi kecocokan jabatan ↔ jenjang:
  - Ahli Muda ↔ 7
  - Ahli Madya ↔ 8
  - Ahli Utama ↔ 9
- [ ] Target lama yang ambigu dikembalikan ke pengguna dengan pesan: *"Target tidak sesuai, silakan pilih ulang"*

### **Layer 4 — Blueprint / Konteks Latihan**
- [ ] Blueprint menerima angka jenjang yang sama dari Layer 3
- [ ] Tidak ada konversi balik ke label teks di tengah alur
- [ ] Target latihan = target yang dipilih pengguna

### **Layer 5 — Chat AI**
- [ ] System prompt atau user message membawa jenjang sebagai angka
- [ ] AI menerima konteks: *"Pengguna menargetkan jenjang 7 (Ahli Muda)"* — bukan hanya *"Ahli Muda"*
- [ ] AI tidak menebak jenjang dari label jabatan

### **Layer 6 — Latihan Ujian**
- [ ] Soal latihan menggunakan target jenjang yang sama dengan blueprint
- [ ] Kunci jawaban sesuai dengan jenjang yang divalidasi server
- [ ] Tidak ada soal yang menargetkan jenjang ambigu
