## 🔍 Analisis Risiko Hydration Next.js (Temuan Kritis)

Koreksi ke-6 mengungkap risiko yang **tidak saya pertimbangkan sebelumnya** dan berpotensi menyebabkan bug yang sulit dideteksi:

### **Alur yang Berisiko**

```
┌─────────────────────────────────────────────────┐
│  SERVER-SIDE RENDER (SSR)                        │
│  • localStorage TIDAK tersedia di server         │
│  • State inisialisasi menggunakan nilai default  │
│    (misal: randomMode = false)                   │
│  • HTML yang dikirim ke browser: toggle = OFF    │
└─────────────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────────────┐
│  CLIENT-SIDE HYDRATION                           │
│  • useEffect / onMount membaca localStorage      │
│  • Menemukan quiz-random-mode = "true"           │
│  • State berubah: randomMode = true              │
│  • UI berubah: toggle = ON                       │
│                                                  │
│  ⚠️ RISIKO: HTML server (OFF) ≠ UI client (ON)  │
│  → Hydration mismatch warning di console         │
│  → Potensi flicker visual (toggle berubah        │
│    sesaat setelah halaman dimuat)                │
└─────────────────────────────────────────────────┘
```

### **Dampak yang Mungkin**

| Dampak | Severity | Keterangan |
|:---|:---|:---|
| Console warning hydration mismatch | Low | Tidak mengganggu fungsi, tapi membingungkan developer |
| Flicker visual (toggle OFF → ON) | Medium | User melihat toggle berubah sesaat setelah load |
| State tidak konsisten di render pertama | Medium | Komponen anak yang bergantung pada `randomMode` mungkin merender dengan nilai salah di frame pertama |
| Error jika pembacaan localStorage gagal tanpa try/catch | **High** | Aplikasi crash saat hydrate jika storage diblokir |

## 📋 Peta Risiko yang Diperbarui

Berdasarkan pemahaman yang diperbaiki, berikut adalah peta risiko aktual untuk fitur `quiz-random-mode`:

| Risiko | Penyebab | Dampak | Status Pemeriksaan |
|:---|:---|:---|:---|
| **Storage diblokir → crash** | Tidak ada `try/catch` pada `localStorage.getItem('quiz-random-mode')` | Aplikasi gagal hydrate | ⏳ Perlu diperiksa |
| **Hydration mismatch** | SSR menggunakan default, client membaca localStorage | Flicker visual, console warning | ⏳ Perlu diperiksa |
| **Data korup (bukan "true"/"false")** | Nilai seperti `{broken` atau `123` di localStorage | Tergantung logika parsing — bisa crash atau fallback | ⏳ Perlu diperiksa |
| **Multi-tab: nilai terbaru terbaca** | Refresh Tab A setelah Tab B menulis | Tab A mendapat nilai terbaru (bukan sinkronisasi real-time) | ⏳ Perlu diperiksa |
| **Key collision** | Key `quiz-random-mode` bentrok dengan aplikasi lain di domain yang sama | Nilai tidak terduga | Low risk, tapi perlu dicek |
