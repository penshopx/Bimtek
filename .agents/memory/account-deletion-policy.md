---
name: Kebijakan hapus akun
description: Keputusan pengguna untuk tahap pengamanan operasi admin SIAP SKK.
---

Nonaktifkan sementara hapus akun.

**Why:** pengguna memilih “Nonaktifkan sementara hapus akun” saat menentukan kebijakan tahap pengamanan admin.

**How to apply:** jadikan keputusan ini batasan implementasi pengamanan admin. Ini bukan izin untuk menghapus akun atau data pengguna, dan bukan keputusan untuk menerapkan soft delete maupun hard delete.
